🤖 REST API v1

Watchtower Appetize API

A production-ready REST API to automate APK uploads to Appetize.io. Monitor GitHub releases, upload on demand, and pass session cookies per-request — designed to be called by AI agents, CI pipelines, and external tooling.

Get Started → View on GitHub

Authentication

All write endpoints require your API key. Read-only endpoints (/status, /release, /logs) are public.

Pass your key using either header:

HTTP
# Option 1 — Authorization header (recommended)
Authorization: Bearer YOUR_API_KEY

# Option 2 — Custom header
X-Api-Key: YOUR_API_KEY
Where to find your key: Open the dashboard → the API Key card on the right side. Click Reveal then Copy.

Quick Start

Three steps to upload an APK via the API:

1. Check status

curl
curl https://your-app.replit.app/api/v1/status

2. Trigger upload (latest release from configured repo)

curl
curl -X POST https://your-app.replit.app/api/v1/upload \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'

3. Upload from a direct APK URL

curl
curl -X POST https://your-app.replit.app/api/v1/upload/url \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"apkUrl":"https://example.com/app.apk"}'

With fresh session cookies (advanced)

Pass Appetize.io session cookies per-request so you don't need to update them on the server:

curl
curl -X POST https://your-app.replit.app/api/v1/upload \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "cookies": [
      {"name":"connect.sid","value":"s%3A...","domain":"appetize.io","path":"/","secure":true,"httpOnly":true,"sameSite":"None"},
      {"name":"appetize_client_id","value":"cid_...","domain":"appetize.io","path":"/","secure":true}
    ]
  }'

POST /upload 🔒 Auth required Download latest release APK and upload to Appetize

All body fields are optional — useful for per-request overrides without touching server config.

FieldTypeRequiredDescription
cookiesCookie[]optionalAppetize session cookies to use for this upload (overrides stored cookies)
apkUrlstringoptionalDirect APK download URL — skips the GitHub release lookup
patstringoptionalGitHub PAT to use for this request (overrides stored PAT)
repoUrlstringoptionalGitHub repo URL to use for this request
// Minimal — upload latest release using stored config
curl -X POST BASE/upload \
  -H "Authorization: Bearer KEY" \
  -H "Content-Type: application/json" \
  -d '{}'

// With per-request cookies
-d '{"cookies":[{"name":"connect.sid","value":"s%3A...","domain":"appetize.io","path":"/","secure":true,"httpOnly":true,"sameSite":"None"}]}'

// Response 200 (async — upload runs in background)
{ "ok": true, "message": "Upload started", "logsUrl": "/api/v1/logs" }

// Response 409 — upload already running
{ "error": "Upload already in progress" }
POST /upload/url 🔒 Auth required Download APK from direct URL and upload
FieldTypeRequiredDescription
apkUrlstringrequiredDirect HTTPS URL to the APK file
cookiesCookie[]optionalOverride session cookies for this upload
curl -X POST BASE/upload/url \
  -H "Authorization: Bearer KEY" \
  -H "Content-Type: application/json" \
  -d '{"apkUrl":"https://github.com/owner/repo/releases/download/v1.0/app.apk"}'
POST /cookies 🔒 Auth required Save Appetize session cookies on the server
FieldTypeRequiredDescription
cookiesCookie[]requiredArray of Playwright-format cookies from Cookie-Editor
curl -X POST BASE/cookies \
  -H "Authorization: Bearer KEY" \
  -H "Content-Type: application/json" \
  -d '{"cookies":[{"name":"connect.sid","value":"s%3A...","domain":"appetize.io","path":"/","secure":true,"httpOnly":true,"sameSite":"None"}]}'

// Response 200
{ "ok": true, "count": 8 }
DELETE /cookies 🔒 Auth required Delete stored session cookies 
curl -X DELETE BASE/cookies \
  -H "Authorization: Bearer KEY"

// Response 200
{ "ok": true }
POST /config 🔒 Auth required Update repo URL and GitHub PAT
FieldTypeRequiredDescription
repoUrlstringoptionalGitHub repo URL (https://github.com/owner/repo)
patstringoptionalGitHub Personal Access Token (required for private repos)
curl -X POST BASE/config \
  -H "Authorization: Bearer KEY" \
  -H "Content-Type: application/json" \
  -d '{"repoUrl":"https://github.com/owner/repo","pat":"ghp_..."}'

// Response 200
{ "ok": true, "repoUrl": "https://github.com/owner/repo", "hasPat": true }
POST /monitor/start  |  /monitor/stop  |  /monitor/check 🔒 Auth required 
// Start automatic monitor (checks every 5 min)
curl -X POST BASE/monitor/start \
  -H "Authorization: Bearer KEY"

// Stop monitor
curl -X POST BASE/monitor/stop  -H "Authorization: Bearer KEY"

// Force an immediate check right now
curl -X POST BASE/monitor/check -H "Authorization: Bearer KEY"

// All return { "ok": true }
POST /stop 🔒 Auth required Kill the active upload process 
curl -X POST BASE/stop \
  -H "Authorization: Bearer KEY"

// Response 404 if no active process
{ "error": "No active upload process" }

Error codes

StatusMeaning
200Success
400Bad request — missing or invalid body field
401Unauthorized — missing or invalid API key
404Resource not found (e.g. no active process to stop)
409Conflict — upload already running
500Server error — check logs via GET /logs
JSON
// Error response shape
{
  "error": "Human-readable error message",
  "hint":  "Optional hint on how to fix it"
}

Python example

Python
import requests

BASE = "https://your-app.replit.app/api/v1"
KEY  = "YOUR_API_KEY"
HEADERS = {"Authorization": f"Bearer {KEY}", "Content-Type": "application/json"}

# Check status
status = requests.get(f"{BASE}/status").json()
print(status["monitor"]["lastUploadedTag"])

# Trigger upload
r = requests.post(f"{BASE}/upload", headers=HEADERS, json={})
print(r.json())  # {"ok": true, "message": "Upload started"}

JavaScript / Node.js example

JavaScript
const BASE    = "https://your-app.replit.app/api/v1";
const API_KEY = "YOUR_API_KEY";

async function upload(apkUrl) {
  const r = await fetch(`${BASE}/upload`, {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ apkUrl }),
  });
  return r.json();
}

// Stream logs
const sse = new EventSource(`${BASE}/logs`);
sse.onmessage = (e) => console.log(JSON.parse(e.data));
